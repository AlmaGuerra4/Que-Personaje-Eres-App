# Que-Personaje-Eres-App
App en iOS tipo cuestionario para determinar que personaje eres
¿Qué personaje eres? 

Es una aplicación en Swift que determina qué personaje eres mediante un cuestionario interactivo.

Personajes incluidos:

- Tony Stark (Iron Man)
- Batman
- Spider-Man
- Sherlock Holmes

¿Cómo funciona ?

1. El usuario responde 5 preguntas
2. Cada respuesta suma puntos a un personaje
3. Se calcula el personaje con mayor puntaje
4. Se muestra el resultado con descripción

Lógica:

- Arreglos (arrays)
- Diccionarios
- Estructuras (struct)
- Ciclos (for)
- Condicionales (if)
